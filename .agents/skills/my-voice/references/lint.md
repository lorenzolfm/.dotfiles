# Lint

Each item is a habit that marks a comment as drafted by Claude rather than written by Lorenzo. Check every draft against every item.

- An em dash (—). Lorenzo's comments have two in three years. Use a period, a comma or parentheses.
- Bold run-in labels (`**The fact.**`), headings, tables or numbered "findings". Rewrite as plain sentences.
- A fix reply that describes the change, like `Done — <restating the change>`. The sha carries it.
- An opening that restates the author's code back to them. Start at the point.
- Stock phrases: "worth noting", "tiny consistency nit", "tell the same story", "heads up", "great question", "hope this helps", "happy to". Cut them.
- Reports of what was verified, provenance notes, or any AI attribution. Cut them.
